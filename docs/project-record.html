SUTRA: live vehicle telemetry and green corridors

An Android app streams each vehicle's position to Supabase. A web console lets traffic control watch the fleet and send alerts, and authorized emergency vehicles can open a green corridor that warns drivers ahead to give way.

App Expo SDK 57 · React Native 0.86 Backend Supabase Postgres, Realtime, Edge Functions Maps MapLibre + OpenStreetMap, no API keys

Architecture

No custom server. The phone writes to Postgres, the database does the work in triggers, and Realtime pushes changes to whoever may see them. Row-level security decides who sees what, so the app and the console share one login and one set of rules.

Features

Driver app

  • Email sign-in; register and choose a vehicle.
  • Streams position every 3 s, or every 1 s for emergency vehicles; works in the background when allowed, and in the foreground if not.
  • Map follows the driver. Search places, or long-press the map to set a destination; fastest route drawn.
  • Alerts beep, vibrate and show a notification with no tap needed.
  • Crashes are captured and shown on the next launch.

Operator console

  • One interface for operators and drivers. Operators see the whole fleet; drivers see only their own vehicles. The database enforces this, not the browser.
  • Live map and list with speed, plate, offline status; filters and sorting.
  • A week of drive history and speeding insights: when, where and how fast.
  • Send alerts to one vehicle or broadcast to all, with category and severity.
  • Active green corridors with junction states and drivers warned.

Retention

A nightly job keeps position history 30 days, alerts 30 days, ended corridors 30 days and speeding records a year. The windows are rows in retention_policy, not code.

Green corridor

An emergency vehicle that an operator has authorized picks a destination and taps Start green corridor. It runs until arrival (within 50 m), until the driver ends it, or for an hour.

All the per-second work runs in one Postgres trigger, so it keeps working while the ambulance app is in the background. The ambulance is not beeped for overspeeding during a corridor, though the violation is still recorded.

Security

  • Emergency privilege is a database flag only an administrator can set; a trigger blocks drivers from granting it to themselves.
  • Every table has row-level security. Corridor tables have no client write policy at all; corridors open and close only through two checked functions.
  • Internal database functions are closed to the public API (migration 10). Before that, anyone could trigger data pruning or the operator-invite sync.
  • No map or routing API keys anywhere. The Supabase anon key in the app is public by design; RLS is the protection.
  • Operators are granted through operator_invites; nobody can promote themselves.

Legal notes for the pitch

Signals are simulated on purpose. In India green corridors are run by the traffic police, mostly for organ transport. A private app has no authority over traffic lights. The simulation shows what connecting to a city’s adaptive signal system would add; that step needs the authorities.

  • Warning drivers to make way is lawful and useful: since 2019, not giving way to an emergency vehicle carries a ₹10,000 fine under Section 194E of the Motor Vehicles Act.
  • Continuous location tracking falls under the DPDP Act 2023 and needs proper consent and a privacy notice before real use.
  • Alerts need no tap, because handling a phone while driving is itself an offence.
  • The Tesla Fleet API does not fit: it covers only consenting Tesla owners’ cars, has no traffic or signal data, and Tesla has few cars in India.
  • This is not legal advice; have it reviewed before a real deployment.

Known limits

  • Alerts reach a running app, including in the background. A fully closed app gets nothing; that needs FCM push.
  • “Fastest” route uses speed limits, not live traffic; live traffic needs the authority’s feed or a paid provider.
  • Only drivers running SUTRA get corridor warnings.
  • The public OSRM, Nominatim and Overpass servers have no uptime guarantee. The junction lookup is often refused or rate-limited, so it retries from the phone; a corridor still starts without junctions if both fail.
  • EAS build artifacts expire after 14 days.

Lessons

  • Silent peer skips. legacy-peer-deps is needed for Expo 57, but it silently skipped three required packages; expo export before every build catches this.
  • Config over env. EAS environment variables never reached the bundle; config lives in app.config.ts instead.
  • Edge to edge. Android draws under the system bars and no longer resizes for the keyboard, so every edge offset needs safe-area insets and keyboard avoidance needs padding.
  • Background tasks. A throw in the background location task kills the app, and a foreground service without notification permission is killed by Android.
  • Overpass. It refuses generic user agents (including okhttp, which React Native sends), so always send a real User-Agent and Accept: application/json.
  • Public functions. Every function in the public schema is a REST endpoint; SECURITY DEFINER helpers need an explicit revoke.
